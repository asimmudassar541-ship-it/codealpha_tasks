# VisionGallery

A modern and responsive image gallery built as part of the CodeAlpha Frontend Development Internship.

## Features

- Responsive image gallery
- Category-based image filtering
- Interactive lightbox
- Next and previous image navigation
- Image counter
- Keyboard navigation
- Hover effects
- Smooth transitions
- Mobile-friendly design
- Image loading error handling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- JavaScript DOM Manipulation

## Gallery Categories

- Nature
- City
- Travel
- Architecture

## Keyboard Controls

| Key | Action |
|---|---|
| Arrow Right | Next image |
| Arrow Left | Previous image |
| Escape | Close lightbox |
