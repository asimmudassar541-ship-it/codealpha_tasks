# 🧮 CodeAlpha Calculator

A modern, responsive, and user-friendly calculator developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulo operation
- 🔢 Number input
- 🔘 Decimal number support
- 🧹 Clear button
- ⌫ Delete button
- 🟰 Result calculation
- ⚠️ Divide-by-zero handling
- ⌨️ Keyboard support
- 📱 Responsive design
- ✨ Modern glassmorphism-style interface
- 🎨 Smooth button hover and click effects

## ⌨️ Keyboard Controls

| Key | Action |
|-----|--------|
| 0–9 | Enter numbers |
| . | Decimal point |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulo operation |
| Enter | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear calculator |
