# 🎵 CodeAlpha Music Player

A modern and responsive music player developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## ✨ Features

- ▶️ Play and pause music
- ⏮ Previous song
- ⏭ Next song
- 🎵 Playlist support
- ⏱ Current time and song duration
- 📊 Interactive progress bar
- 🔊 Volume control
- ⌨️ Keyboard controls
- 🔄 Automatic next song
- 🖼️ Album cover display
- 📱 Responsive design
- ✨ Modern dark/glassmorphism interface
- 🎨 Smooth hover and transition effects

## ⌨️ Keyboard Controls

| Key | Action |
|-----|--------|
| Space | Play / Pause |
| ← | Previous Song |
| → | Next Song |
| ↑ | Increase Volume |
| ↓ | Decrease Volume |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- Visual Studio Code
- Git
- GitHub
